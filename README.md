# AI Resume Screening & Candidate Ranking System

## Project Overview

This project screens resumes and ranks candidates based on their skills and resume scores using Python.

## Objective

* Screen resumes automatically.
* Rank candidates based on scores.
* Filter candidates by job role.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Jupyter Notebook

## Dataset

The dataset contains Resume ID, Skills, Job Role, and Resume Score.

## Project Workflow

1. Load resume dataset.
2. Check and clean data.
3. Rank candidates by score.
4. Filter candidates by job role.
5. Display top candidates.
6. Visualize candidate ranking.

## Output

* Ranked candidate list.
* Top 5 candidates.
* Candidate ranking bar chart.
